## Layout
- `Game/`: Unreal project (`.uproject`, `Config/`, `Content/`, `Source/`). Created from the
  Unreal editor; not generated by Claude unless asked.
- `Art/Source/`: Blender `.blend` source files, one folder per asset.
- `Art/Export/`: FBX/texture exports ready for Unreal import (mirror of `Art/Source/`).
- `Tools/blender/`: Blender Python scripts (run with `blender -b ... --python ...`).
- `Tools/unreal/`: Unreal editor Python scripts (Python Editor Script Plugin).
- `Docs/`: asset list and style brief. Follow them when making assets.

## Naming
Prefix + PascalCase name + optional variant: `SM_Crate_A`, `T_Crate_A_D`.
- Assets: `SM_` static mesh, `SK_` skeletal mesh, `M_` material, `MI_` material instance,
  `T_` texture, `A_` animation, `BP_` blueprint, `S_` sound, `SC_` sound cue.
- Texture suffixes: `_D` base colour, `_N` normal, `_ORM` occlusion/roughness/metallic, `_E` emissive.
Collision meshes in Blender: `UCX_<MeshName>_00`. LODs: `<MeshName>_LOD0`, `_LOD1`...

## Scale and export
- 1 Blender unit = 1 metre. Scene unit scale 1.0, Z-up, -Y forward (Blender default).
- Apply transforms (Ctrl+A → All Transforms) before export. Origin at the base of the asset.
- FBX export (`Tools/blender/export_fbx.py` does this): selected objects, mesh only,
  Apply Scalings = FBX All, Forward = -Y, Up = Z, Smoothing = Face, no leaf bones,
  embed textures off. Import in Unreal at scale 1.0.
- Budgets (edit to taste): props ≤ 5k tris, hero assets ≤ 30k, textures ≤ 2048² (4096² for hero).
